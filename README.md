# ARQUIVO 13 — Mistérios de São Sebastião

Protótipo inicial do capítulo **A Casa Sem Dono**.

## Como testar
Abra `index.html` em um navegador moderno ou publique os arquivos em hospedagem estática. Funciona sem bibliotecas externas.

**PC:** WASD para andar, setas esquerda/direita para girar, mouse arrastando para olhar, E para inspecionar.

**Celular:** tela horizontal, botões de movimento e arrastar na cena para olhar; botão INSPECIONAR.

## Escopo implementado
- Renderização 3D simplificada por raycasting (não é ainda a arte 3D final).
- Navegação em primeira pessoa por cômodos.
- Três evidências investigáveis e diário de evidências.
- Mecanismo do depósito que exige as três pistas e conclusão do primeiro objetivo.
- Layout responsivo PC/Android.

## Ainda pendente
Modelos 3D realistas, iluminação avançada, áudio/vozes, sistema de inventário, salvamento, NPCs, IA de perseguição, demais capítulos, cooperação e servidor.

**Status:** protótipo inicial de código, ainda sem testes em dispositivos reais. Não há implantação no Render.
